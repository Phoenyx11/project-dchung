# THE HABIT TRACKER-INATOR

This Habit Tracker-inator lets users track their most important habits and tasks. 
It allows users to add, remove, and complete tasks (which can be completed one time on one
day) and habits (which can be completed once per day of the week). It also allows users to view daily and weekly summaries of their tasks and habits. 

## How to use

To use the Habit Tracker-inator, simply enter the number of the function you would like to 
perform when prompted! The app will then take you to a sub menu where you can select one 
of the following options:

### Add Task

To add a task, first enter the day of the week you would like to add the task to, then 
enter the name of the task. 

### Add Habit

To add a habit, enter the name of the habit when prompted. 

### Complete Task

To complete a task, you will be asked to enter the name of the task you completed after 
the system shows you a list of all current incomplete tasks. If all tasks are complete, 
the system will tell you all your tasks are complete and return to the main menu. 

### Complete Habit

To complete a habit for a particular day, enter the name of the habit from the list of 
habits you will be shown. Then enter the day of the week you completed the task on. 

### Remove Task

To remove a task, enter the day of the week the task you want to remove is on. The system 
will show a list of tasks on that day. It will then ask you to enter the name of the task 
to remove, and will do so as long as it can be found. 

### Remove Habit

To remove a habit, enter the name of the habit to remove (a list of active habits will be 
displayed). If the habit can be found it will be removed. 

### Weekly Report

The weekly report function will display all habits and how many days they have been 
completed, as well as a list of complete and incomplete tasks. 

### Daily Report

The daily report does a similar thing to a weekly report, just for a singular day. It will 
ask the user for the day they want the report for, then display a list of complete and 
incomplete tasks and habits for the selected day.
